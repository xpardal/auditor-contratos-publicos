# Código de conducta

Este proyecto adopta el [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) como su código de conducta para autoría, *issues*, *pull requests* y cualquier otra interacción asociada al repositorio.

## Resumen

- Trato respetuoso y profesional, especialmente con usuarios sin perfil técnico.
- Tolerancia cero al acoso, lenguaje discriminatorio o ataques personales.
- Las críticas son sobre el código y la metodología, no sobre las personas.
- Las personas mantenedoras pueden eliminar contenido o vetar usuarios que infrinjan estas normas.

## Cómo reportar

Para denunciar un comportamiento inaceptable, contacta con las personas mantenedoras mediante el canal interno disponible para el repositorio privado. Los avisos se tratarán con confidencialidad.

## Atribución

Texto adaptado del [Contributor Covenant, versión 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
